# 12_OPERATION_FLOW_TEST

## 目的

管理画面で変更した内容が HOME 表示へ正しく反映されることを確認する。

対象:
- 追加
- 削除
- 並び替え
- 速度変更

## 前提条件

- 開発環境を起動済みであること。
- HOME データ取得 API が有効であること。
- 管理画面で対象データを更新できること。

## 参照先

- HOME 画面: `http://localhost:4324/`
- HOME データ API: `http://localhost:4324/api/home.json`

## テストケース 1: 追加反映

手順:
1. 管理画面で HAIR モニター用画像を 1 件追加して保存する。
2. `api/home.json` の `hairMonitor.items` に追加画像が含まれることを確認する。
3. HOME を再読み込みし、HAIR モニターのランダム切替で追加画像が表示されることを確認する。

期待結果:
- API で追加画像が取得できる。
- UI 上で追加画像が表示される。

## テストケース 2: 削除反映

手順:
1. 管理画面で HAIR または PHOTO モニター用画像を 1 件削除して保存する。
2. `api/home.json` から該当画像が消えていることを確認する。
3. HOME を再読み込みし、削除画像が表示されないことを確認する。

期待結果:
- API で削除画像が返らない。
- UI で削除画像が表示されない。

## テストケース 3: 並び替え反映

手順:
1. 管理画面でメインビジュアル画像の並び順を変更して保存する。
2. `api/home.json` の `mainVisual.items` が新しい順序で返ることを確認する。
3. HOME を再読み込みし、メインビジュアルの初期表示とスライド順が変更後の順序に一致することを確認する。

期待結果:
- API の順序が管理画面の並び順と一致する。
- UI の表示順が API と一致する。

## テストケース 4: 速度変更反映

手順:
1. 管理画面で以下の速度を変更して保存する。
   - `mainVisual.transitionSeconds`
   - `hairMonitor.transitionSeconds`
   - `photoMonitor.transitionSeconds`
2. `api/home.json` で各値が更新されていることを確認する。
3. HOME を再読み込みし、メインビジュアルと各モニターの切替間隔が変更後の値に近いことを確認する。

期待結果:
- API の速度値が更新されている。
- UI の切替間隔が更新後の値に追従している。

## 判定基準

- 4 テストケースすべてで期待結果を満たした場合: 合格
- 1 件でも期待結果を満たさない場合: 不合格
