# プロジェクト概要

- プロジェクト名: Lab Hair Design
- 本サイトは WordPress（SWELL子テーマ）で制作する。
- 目的は一般的な美容室ホームページではなく、ブランドサイトとして世界観を育てることにある。
- コンセプトは「育つホームページ」。
- 写真を主役に据え、視覚体験を中心に設計する。
- 開くたびに少し違う表情があり、季節によって変化する構成を目指す。
- 静岡の街と一緒に育っていくサイトとして長期運用を前提にする。
- 5年以上運用できる設計を最優先とする。
- 保守性、表示速度、拡張性を重視する。

# コンセプト

- このサイトは美容室の情報提供サイトではなく、ブランド体験を提供するためのサイトとする。
- テーマは「育つホームページ」。
- 写真を主役にし、視覚で世界観を伝える。
- 開くたびに少し違う印象になる設計を目指す。
- 四季によって少しずつ表情が変わるサイトとして運用する。
- 静岡の街と一緒に育っていく存在を目指す。
- 情報を読むサイトではなく、世界観を感じるサイトを目標とする。
