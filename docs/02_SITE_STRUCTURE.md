# 02_SITE_STRUCTURE

## サイト全体構成

Lab Hair Designは、美容室の情報を並べるホームページではなく、一つのブランドを体験するサイトとして設計する。

サイト構成は必要最小限とし、写真と世界観を主役にする。

各ページの役割は以下の通りとする。

- HOME
ブランドの入口。写真が生きているように変化し、世界観を体験するページ。

- HAIR
ヘアデザイン作品を掲載するギャラリー。作品追加だけで更新できる構造とする。

- PHOTO
ブランドの世界観を伝える写真ギャラリー。HAIRとは独立して管理する。

- STAFF
美容師紹介ではなく、ブランドを作る人物紹介として設計する。

- MENU
料金表ではなく、予約導線を意識したシンプルな構成とする。

- SALON
店内写真・コンセプト・空間を伝えるページ。

- ACCESS
地図・営業時間・駐車場など来店情報をまとめる。

- RESERVE
予約方法を迷わせない導線を設計する。

Instagramはサイト全体と連携し、ブランドの更新情報として活用する。

今後追加する機能は、既存構造を壊さず拡張できる設計を前提とする。
